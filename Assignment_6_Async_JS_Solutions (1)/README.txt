ASSIGNMENT 6 – ASYNC PROGRAMMING WITH JAVASCRIPT
Complete solutions for Q1–Q10.

How to run:
1. Extract this ZIP file.
2. Open the folder in VS Code.
3. Run an individual file in the VS Code terminal:
   node Q1_Coffee_Maker.js
   (Replace the filename for another question.)

Requirements:
- Node.js 18+ is recommended for Q6 because it provides built-in fetch().
- Q6 needs an internet connection to access Fake Store API.
- Q6's optional HTML card bonus runs in a browser page containing:
  <div id="product-container"></div>
- Q5 runs the nested-callback version by default. To run async/await instead,
  comment out runWithCallbacks() and uncomment runWithAsyncAwait().

Random failures are intentional in questions that ask for failure simulation.
Run those programs again if a random failure occurs.
