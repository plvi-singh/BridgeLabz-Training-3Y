ASSIGNMENT 7 – DOM MANIPULATION SOLUTIONS

There are 9 question folders. Each folder contains:
- Qn.html: page structure
- Qn.css: styling
- Qn.js: JavaScript logic

How to run:
1. Extract the ZIP.
2. Open the required Q1, Q2, ... Q9 folder.
3. Open its HTML file in a browser (double-click it, or use VS Code Live Server).
4. Try the interaction described in the question.

Notes:
- Q5 uses Picsum image URLs, so an internet connection is needed for images.
- All solutions use core HTML, CSS and JavaScript; no frameworks.
- Q7 reports clientX/clientY viewport coordinates and places dots relative to the box.
- Q8 uses a document click listener in the capturing phase to close the dropdown when clicking outside.
