ASSIGNMENT 8 – OOP AND ARRAY METHODS IN JAVASCRIPT
Contains separate solutions for Q1 to Q9.

How to run:
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open Terminal in VS Code.
4. Run one file at a time, for example:
   node Q1_Student_Result.js

Requirements:
- Node.js installed.
- No external packages or frameworks are required.

Notes:
- Q1 uses example grade boundaries: A >= 80, B >= 60, C >= 40, otherwise F.
- Q5 demonstrates fare as Rs. 12 per kilometre; the assignment does not specify a fare rate.
- Q6 inventory value is calculated as price multiplied by stock for each product.
