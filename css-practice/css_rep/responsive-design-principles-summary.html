Responsive Design Principles

Three core ideas behind adaptable web pages.

Fluid Layouts

Use relative sizes so content can expand or shrink with the viewport.

width: 90%;
max-width: 1100px;

Flexible Media

Images and media should fit inside their containers without overflowing.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Change the layout when the available screen space needs a different structure.

@media (max-width: 600px) {
  .box { width: 100%; }
}
