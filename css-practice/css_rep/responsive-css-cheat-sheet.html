Responsive CSS Cheat Sheet

Quick reference for important responsive techniques.

Filters

Modify visual appearance.

filter: grayscale(100%);

Media Queries

Apply styles at specific screen sizes.

@media (max-width: 700px) { }

Responsive Design

Make layouts adapt to available space.

width: min(1100px, 90%);

Typography

Scale text smoothly with the viewport.

font-size: clamp(1rem, 2vw, 1.5rem);
Resize the screen to see the layout change.
